# Security

qFilm is a desktop app that works on files on your own computer. It makes no network request of its own: no
account, no upload, no analytics.

If you find a vulnerability (for example a crafted photo or frame archive that crashes the app or reads files it
should not), please report it privately through GitHub: **Security**, then **Report a vulnerability**, on this
repository. Please do not open a public issue for it.

You can expect an answer within a few days. qFilm is a personal project, so there is no formal support or
bug-bounty programme.
